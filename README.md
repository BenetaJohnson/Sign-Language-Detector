# Sign Language Translation System ✋🤟

A computer vision-based **sign language translation software** that recognizes hand gestures, translates them into text in real time.  
This project leverages **deep learning** and **transfer learning with MobileResNet** to enable real-time gesture recognition, promoting accessibility and inclusivity for the deaf and hearing communities.

---

## 🚀 Features
- **Real-Time Gesture Recognition**: Detects and interprets sign language gestures using deep learning.  
- **Text Translation**: Converts recognized gestures into meaningful text.  
- **Lightweight Model**: Built on MobileResNet for efficiency and real-time performance.  

---

## 🛠️ Tech Stack
- **Python 3.11+**
- **TensorFlow / Keras**
- **OpenCV** (for video stream & image processing)
- **NumPy, Pandas** (data handling)
- **Matplotlib / Seaborn** (visualization)
- **Jupyter Notebook / Colab** (for experimentation)
